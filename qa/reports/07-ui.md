Details for the multi-part rows:

- **Stuck inputs, touch:** fingers are released on lift, cancel, sliding off a button, pause from any device, leaving gameplay, leaving touch mode, and focus loss. A finger that stays down through a pause steers again on its next move (by design).
- **Phone layout:**
  - The game is 16:9. On 19.5:9 phones it is height-limited, so a side notch falls in the letterbox bar (about 77 CSS px each side at 844×390, scale 1.625).
  - The shell has no `viewport-fit=cover`, so browsers keep the page out of the cutout anyway.
  - The JUMP button's bottom edge is 33 game px (about 54 CSS px) above the bottom, so it is clear of the home indicator.
  - Hit radii at a small 667×320 phone (scale 1.33): pad 75, JUMP 66, pause 32 CSS px (a 64 px target).
  - Portrait shows Display's rotate hint.
- **Font originality:**
  - "Sproto Pixel" comes from hand-written glyph tables in `ui/font/make_font.py`: `#`/`.` rows, 5×7 and 7×7.
  - No external font is loaded or sampled; PIL only writes the PNG.
  - Regenerating from the script gives pixel-identical PNGs for all 4 sheets.
  - The 5×7 shapes match generic dot-matrix letterforms, which is unavoidable on that grid. The bold set (2 px stems, navy outline) is not a copy of any game's HUD font that I know of.
- **Audio originality and names:**
  - Everything is synthesised with numpy (square, triangle and noise voices) in `audio/tools/make_audio.py`. It reads no samples, MIDI or soundfonts; it only writes WAVs to a temp folder and Ogg files.
  - The melodies are note lists written in the script: z1 is D major at 150 BPM, title is G major at 120 BPM. Reading them, I found no recognisable existing theme. The director's listen is still a manual item (UI-G6).
  - The Ogg files carry no metadata tags.
  - The 23 SFX names match the contract.
